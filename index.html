Cloud Architecture & Deployment

How this very site gets from a commit to your browser.

GitHub Repo

ce-khayal/cloud-portfolio

Source of truth. Every change is a commit on main.

GitHub Actions

CI/CD

A push triggers the workflow that builds and publishes the site.

Azure Static Web Apps

West Europe · Free Tier

Static files served from Azure's global edge network.

Custom DNS + Free SSL

HTTPS

A CNAME record maps the domain; Azure issues the certificate.

.github/workflows/azure-static-web-apps.yml (simplified)
on:
  push:
    branches: [ main ]
jobs:
  build_and_deploy:
    steps:
      - uses: actions/checkout@v4
      - uses: Azure/static-web-apps-deploy@v1
        with:
          app_location: "/"
          output_location: ""
